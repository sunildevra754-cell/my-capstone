# My Capstone App

Stack: React (Vite), JavaScript

Conventions:
- Commit messages Conventional Commits format me
- Components PascalCase me naam (e.g., Header.jsx)
- Functional components + hooks use karo
- Forms must validate every field with specific rules (min length, regex, format) — never leave validation to AI's guesswork
- Always specify exact fields and constraints in prompts; vague prompts produce plausible-looking but incomplete features
- Ask AI to write and run tests before accepting form or validation logic code
